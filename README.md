# TypeScript Practice Problems

Solutions to 8 TypeScript problems covering optional parameters, union types, type narrowing, readonly tuples, generics, interfaces, classes with access modifiers, and async functions.

## Assignment Overview

This assignment has 8 small problems that practice core TypeScript skills. Each problem gives a function or class specification, requirements, and sample input and output. The goal is to write type-safe code that matches the exact output formats, without using `any`.

| # | Problem | Main concept |
|---|---------|--------------|
| 1 | `multiplyValue` | Optional parameters, handling `0` |
| 2 | `processInput` | Union types, `typeof` narrowing |
| 3 | `formatCoordinate` | `readonly` tuples |
| 4 | `concatenateArrays` | Generics, rest parameters |
| 5 | `getPopularCourses` | Interfaces, non-mutating `filter` |
| 6 | `pluckValues` | Generics with `keyof` |
| 7 | `Employee` / `Manager` | Classes, inheritance, access modifiers |
| 8 | `validateAgeAsync` | Async functions, `Promise<string>`, rejecting with `Error` |
